# OpenWorkMate

后台侧栏的快捷加号能直接打开知识上传或系统接入表单。企业外观的修改只影响预览，撤销不会写入配置，保存后才生效。

员工端左侧可新建、切换对话；「文件结果」和有权限的「管理后台」入口在侧栏底部。手机点击左上角菜单展开。

通用问答支持「找图：主题」搜索公共图库和「画：主题」生成 PNG 矢量插画。图片直接展示，可点击放大；插画由同一个聊天模型设计，保存 7 天，不提供照片级生成。

企业问答、通用问答和本地升级共用 `OPENAI_CHAT_MODEL`（默认 `gpt-6.2-sol`）；GPT‑6 的原生业务工具需要 Responses 写权限。缺少该权限时只回答知识问题，并明确提示未执行业务。

输入框上方可切换「企业问答 / 通用问答」。企业模式检索制度并使用已授权的业务工具；通用模式直接问模型，不带企业对话历史，需要启用真实模型。

[本地升级实验台](docs/local-upgrade.md)：在对话里提需求，试用独立分支，确认后手动合并。

本地员工对话可用 `/升级 新增……工具` 直接创建模型编程任务：生成独立功能源码，自动测试和预览，维护者确认后才合并。

文件结果支持生成、在线预览及下载 Excel（XLSX）；编号和公式样文本按原文导出。

企业内部的 AI 工作伙伴。员工对话与管理后台共用一个 Web 服务。安装与部署见 [项目首页](README.md)。

支持按企业定制品牌、真实模型混合检索及图表导出。[本地配置与桌面端边界](docs/local-workspace.md)。

文件结果支持 MD、CSV、PNG 和 MP4 的状态、预览与下载；macOS 桌面端支持快捷键与指定目录保存。
