# 管理后台

工作台可直接打开知识上传和连接器创建表单。侧栏提供知识库、Skill、系统接入和审计。

- 上传知识时可选择文件或录入文本，并设置可见范围。处理后可在知识库页面验证检索。
- 创建只读连接器时填写系统名称和完整查询地址。高级配置支持系统类型、认证、GET 或 POST、健康检查路径与能力标识。凭证使用服务端环境变量名。复杂请求映射通过 [HTTP 接入 API](../docs/connector-http-integration.md) 配置。
- 管理后台要求 `platform-admin` 或 `business-owner` 角色，各项操作还需通过后端接口校验。

在根目录运行 `pnpm dev`，从 [127.0.0.1:5180/admin/](http://127.0.0.1:5180/admin/) 进入。单独运行 `pnpm admin:dev` 时入口为 [127.0.0.1:5174/admin/](http://127.0.0.1:5174/admin/)。

生产部署由后端服务在 `/admin/` 提供页面，员工入口、后台与 API 使用同一域名。
