# OpenWorkMate

[ローカル更新ラボ](docs/local-upgrade.md)：チャットから変更を提案し、独立したブランチで試してから手動で統合します。

<!-- upgrade:formats -->

ファイル結果は Excel（XLSX）の生成・プレビュー・ダウンロードにも対応しています。

社内向けの AI ワークスペースです。従業員向けのチャットと管理画面を同じ Web サービスで提供します。セットアップとデプロイについては [README](README.md) をご覧ください。

テナント別のロゴと配色、ベクトル検索、表・グラフの出力に対応しています。[ローカル環境とデスクトップ版の設計](docs/local-workspace.md)。

MD・CSV・PNG・MP4 の生成状態、プレビュー、ダウンロードに対応。macOS 版ではショートカットで呼び出し、選択したフォルダーに保存できます。
